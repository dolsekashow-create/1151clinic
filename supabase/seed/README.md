# Seed — البيانات المرجعية

هذا المجلد مخصص **للبيانات المرجعية فقط**:

- الصلاحيات (`permissions`) — تُولَّد من `packages/core/src/permissions/catalog.ts`
- الأدوار الأولية (`roles`) وربطها بالصلاحيات
- وحدات القياس وتصنيفات الأصناف الأساسية

## ممنوع هنا

- بيانات عملاء حقيقية
- بيانات مالية
- أي بيانات إنتاج
- أي مفاتيح أو أسرار

## الحالة

فارغ في **المرحلة 1** — لا توجد جداول بعد.

يبدأ التعبئة في **المرحلة 2** مع جداول الهوية والصلاحيات، عبر ملف `seed.sql`
يُولَّد من كتالوج الصلاحيات حتى يبقى مصدر الحقيقة واحدًا (الكود) ولا يتفرّع.
